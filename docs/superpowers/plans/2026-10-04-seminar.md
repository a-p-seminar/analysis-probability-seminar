# Seminar archive implementation plan

Scope update: the user requested a five-record frontend/backend preview before uploading all data. Full import is preserved locally under ignored `.local-data/full-import/`; only five records and two PDF files belong in this delivery. Full-data publication is deferred at the user's request.

> For agentic workers: use superpower-executing-plans and dispatch independent scoped tasks using superpower-dispatching-parallel. The specification is `docs/contract.md`.

**Goal:** Deliver a complete seminar archive, admin editor, PDF viewer and GitHub upload source, ready for Netlify without content-triggered rebuilds.

**Architecture:** Vite multi-page frontend requests content at runtime. A same-origin Netlify API authenticates one administrator, stages large files in 2 MiB chunks and commits content and attachments to GitHub. Local adapters make the same backend runnable without cloud credentials.

**Tech stack:** Node 22+, React, Vite, PDF.js, Netlify Functions/Blobs, GitHub REST, Python source importer, node:test, browser checks.
